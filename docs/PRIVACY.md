# Политика конфиденциальности «ЗаказПро»

Заказы, профиль, черновики, настройки, резервные копии и данные браузера Kwork хранятся на компьютере пользователя в выбранной папке данных. Локальные журналы установщика помогают проверить установку. Программа не отправляет эти файлы или диагностические сведения разработчикам автоматически.

**Ollama.** При анализе и генерации данные выбранного заказа и необходимый контекст профиля передаются локальному HTTP-серверу Ollama на этом компьютере. Загрузка модели обращается к сети только по действию пользователя. Собственные настройки Ollama и её сетевое поведение регулируются самой Ollama.

**Kwork.** Поиск и открытие площадки отправляют запросы на Kwork. Авторизация проходит в отдельном профиле WebView2 на компьютере пользователя. Данные сессии могут храниться в этой папке. ЗаказПро сохраняет отклики как черновики и не отправляет их на площадку автоматически.

**Обновления.** При настроенном адресе клиент может при запуске и по кнопке запрашивать подписанные сведения о версиях по HTTPS. Сервер видит обычные данные сетевого запроса, например IP-адрес и время. Запрос не содержит заказов, профиля пользователя, черновиков или логов.

**Поддержка.** При открытии ссылок поддержки внешний сайт видит обычный браузерный запрос. Приложение не прикрепляет файлы и не заполняет отчёт вашими данными. GitHub Issues — публичные обращения. Публикуйте только сведения, которые готовы раскрыть. Условия сторонних сервисов применяются к их площадкам.

**Управление данными.** При штатном удалении программа по умолчанию сохраняет папку данных. Её удаление требует отдельного флажка и подтверждения. Резервные копии, созданные вне неё, нужно хранить или удалять самостоятельно.

**Добровольная финансовая поддержка.** Кнопка в настройках открывает официальную страницу поддержки в системном браузере; с неё пользователь переходит на CloudTips. Приложение не передаёт профиль, заказы или базу в этот переход и не обрабатывает финансовые операции и платёжные или персональные данные CloudTips. На внешнем сайте действуют его условия обработки данных. Поддержка не влияет на доступность функций.
