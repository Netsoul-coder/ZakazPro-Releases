# Руководство пользователя

## Установка

1. Проверьте [системные требования](REQUIREMENTS.md). На странице нужного выпуска скачайте Setup.exe, Setup.exe.manifest.json и Setup.exe.sig в одну папку.
2. Получите проверяющий скрипт и открытый ключ проекта по доверенному каналу. В PowerShell 7 запустите скрипт OpenVerifiedUpdate.ps1 с параметром -Installer и путём к Setup.exe. Скрипт проверит подпись манифеста и SHA-256, затем откроет мастер. Параметр -VerifyOnly выполняет только проверку. При ошибке используйте заново скачанный комплект из проверенного источника.
3. В мастере выберите отдельные папки программы и данных. Для переноса включите «Перенести данные из другой папки или файла SQLite», укажите прежнюю папку или SQLite и выберите новую папку назначения. Завершите работу старой программы и закройте её окно Kwork перед копированием.
4. Проверьте пути на странице «Установка». Нажмите «Установить», затем «Готово». Открыть программу также можно из меню «Пуск».

## Заказы и отклики

1. Заполните вкладку «Профиль» и нажмите «Сохранить профиль».
2. На вкладке «Заказы» нажмите «Найти заказы» для поиска на Kwork или «Добавить заказ» для ручного ввода. Щёлкните запись, чтобы открыть карточку. «Открыть Биржу Kwork» открывает отдельное окно браузера. Для распознавания заказа при поиске используйте поддерживаемые программой страницы.
3. Для анализа выберите карточку и нажмите «Анализировать». При необходимости откройте «Настройки» → «Проверить подключение» и проверьте локальную Ollama с gpt-oss:20b.
4. Нажмите «Подготовить отклик». В редакторе можно написать текст вручную либо нажать «Сгенерировать», проверить текст и нажать «Сохранить». Это сохраняет черновик в ЗаказПро. Отправку на площадке пользователь выполняет отдельно.

## Резервное копирование и обновление

В «Настройках» нажмите «Создать копию базы». Закройте окно Kwork перед копированием профиля браузера. Для восстановления выберите «Восстановить базу», укажите резервную копию и новую папку. Сверьте записи и черновики после открытия.

В «Настройках» нажмите «Проверить обновления». При настроенном канале программа покажет доступную совместимую версию. Можно открыть её страницу или нажать «Позже». Скачайте комплект и проверьте подпись перед запуском. Закройте ЗаказПро, откройте проверенный мастер и оставьте текущую папку данных. При прерывании обновления повторно запустите тот же проверенный установщик для восстановления. Если канал недоступен, можно использовать локальный подписанный комплект.

## Удаление

1. Закройте ЗаказПро и окно Kwork.
2. В Windows откройте «Параметры» → «Приложения» → «Установленные приложения». У записи «ЗаказПро» выберите «Удалить».
3. В деинсталляторе оставьте выключенным флажок «Также удалить папку пользовательских данных и её резервные копии». Нажмите «Удалить». Для переустановки проверьте предложенные прежние пути.

## Обратная связь

На GitHub откройте Issues → New issue и выберите форму ошибки или предложения. Укажите версию «ЗаказПро» и Windows, шаги, ожидаемый и фактический результат. Используйте вымышленные примеры. Перед добавлением снимка закройте имена клиентов, адреса и содержание коммерческих заказов. В следующей сборке ссылки будут доступны в «Настройки» → «Обратная связь».

## Добровольная поддержка проекта

В разделе «Настройки» нажмите «Поддержать проект». Откроется страница поддержки официального сайта. Для добровольного перевода перейдите с неё на CloudTips. Все функции приложения бесплатны. Приложение не принимает платежи и не получает введённые на стороне CloudTips платёжные и персональные данные.
