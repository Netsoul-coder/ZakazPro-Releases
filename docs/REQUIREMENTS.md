# Системные требования

## Приложение

| | Минимальная оценка для приложения | Рекомендуемая оценка для приложения |
| --- | --- | --- |
| ОС | Windows 11 x64 | Windows 11 x64 |
| Процессор | 2 логических ядра | 4 логических ядра |
| ОЗУ компьютера | 4 ГБ | 8 ГБ |
| Свободное место | 1 ГБ для установки плюс место для данных | 2 ГБ плюс запас для данных и резервных копий |
| Kwork | Microsoft Edge WebView2 Runtime и доступ к Kwork | То же |

Числа для CPU, ОЗУ и места — предварительные оценки, границы на таких конфигурациях не испытаны. Проверенный сценарий был на Windows 11 x64. Пакет включает среду .NET. Место для моделей Ollama оценивается отдельно.

## Локальные модели ИИ

ЗаказПро 1.0.0 рассчитывает на Ollama с gpt-oss:20b. У модели размер около 14 ГБ. Документация модели указывает возможность запуска на системах с 16 ГБ памяти. Для установки Ollama её документация указывает минимум 4 ГБ дискового места. На одной тестовой машине NVIDIA RTX 5060 Ti с 16 ГБ видеопамяти обработала все 25 слоёв модели через CUDA. Это подтверждение конкретной конфигурации, а не универсальное требование к GPU. [Карточка модели](https://ollama.com/library/gpt-oss:20b) · [Ollama для Windows](https://docs.ollama.com/windows)

Для планирования запаса под Windows, Ollama и модель ориентируйтесь на 24 ГБ свободного места и 24 ГБ системной ОЗУ для сценария без достаточной видеопамяти. Эти величины оценочные и не гарантируют скорость.

На менее мощных компьютерах можно вести базу и писать черновики вручную без генерации ИИ. Поддержка меньших моделей потребует отдельной проверки качества и совместимости форматов анализа и отклика. В 1.0.0 переключение модели для этих задач не заявлено.
