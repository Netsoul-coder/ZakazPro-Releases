# ЗаказПро

Приложение Windows для просмотра и сохранения заказов, анализа через локальную Ollama и подготовки черновиков откликов.

- [Руководство пользователя](docs/GUIDE.md)
- [Системные требования](docs/REQUIREMENTS.md)
- [Конфиденциальность](docs/PRIVACY.md)
- [История изменений](CHANGELOG.md)

Установочные файлы размещаются в разделе **Releases**. Ошибки и предложения принимаются в **Issues**. Не прикладывайте базы заказов, авторизованные профили браузера, пароли и ключи.
